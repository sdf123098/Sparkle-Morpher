# Sparkle's Morpher (SPM) — スパークルの変身器

> [English](README.md) | [中文](README_zh.md) | **日本語** | [한국어](README_ko.md)

**クライアント専用の Minecraft カスタムモデル MOD** です。カスタム 3D モデル、テクスチャ、アニメーション、効果音でキャラクターを着飾り、どの Minecraft サーバーでも、SPM を導入したプレイヤー同士でお互いのモデルを表示できます。

**SPM はクライアントに導入するだけで使えます。Minecraft サーバーへの SPM やプラグインの導入、設定変更は不要です。** マルチプレイのモデル共有には SPM Cloud を使用します。双方が同じ Cloud インスタンスに接続し、現在のゲームアカウントの本人確認と連携を行い、相手がアクセスできる Cloud モデルを選択してください。

<a id="quick-start"></a>
## クイックスタート

1. [Releases](https://github.com/sdf123098/Sparkle-Morpher/releases) から、**Minecraft のバージョンとローダー**に合うビルドをダウンロードします。6 種類のビルドは下の表を参照してください。
2. SPM の `.jar` をクライアントの `mods` フォルダーに入れます。Fabric ビルドには Fabric API も必要です。選んだリリースが追加の依存 MOD を要求する場合は、それらも導入してください。対応する Fabric または NeoForge のプロファイルで Minecraft を起動します。
3. ワールドまたはサーバーに入り、**Alt + Y** でモデルパネルを開きます。ローカルモデルをインポートするか Cloud モデルを選び、テクスチャや設定を選択します。**Z** でアニメーションホイールを開きます。キー割り当ては Minecraft の操作設定で変更できます。
4. 外観を共有するには、双方が**同じ Cloud インスタンス**を選び、ログインして現在のゲームアカウントを連携します。公開 Cloud モデルを選ぶか、自分のモデルをアップロードして公開してください。プライバシーモードが無効であることも確認します。相手の SPM クライアントが、アクセス可能なモデルを自動でダウンロードして表示します。

ローカルモデルの使用には Cloud の設定は不要です。ローカルへのインポートだけでは、モデルは自動でアップロード・共有されません。

<a id="multiplayer"></a>
## どのサーバーでもお互いのモデルを表示

SPM のモデル共有は Minecraft サーバーの MOD 構成から独立しています。バニラサーバー、プラグインサーバー、MOD サーバーのいずれでも、管理者に SPM の導入を依頼する必要はありません。

| 利用状況 | 表示結果 |
|---|---|
| 双方が SPM を導入し、同じ Cloud を使用し、ゲームアカウントの本人確認を完了して、アクセス可能な Cloud モデルを使用 | 各クライアントに相手のカスタムモデルとテクスチャが表示されます。対応するモデル設定やホイール/待機アクションも同期します。 |
| 相手が SPM を導入していない | 相手には通常の Minecraft の外観が表示されます。 |
| モデルをローカルにだけインポートした | ローカルで使用できますが、Cloud で自動共有されません。 |
| 異なる Cloud を使用、ゲームアカウントが未連携、またはモデルへのアクセス権がない | これらの条件を解決するまで、Cloud による外観共有は利用できません。 |

モデルリソースと外観の更新は **SPM クライアントと SPM Cloud** の間で送受信されます。Minecraft サーバーは引き続きゲーム処理を担当します。モデルの置き換えはクライアントの描画を変更するもので、サーバーのルール、当たり判定、権限は変更しません。

<a id="model-formats"></a>
## モデル形式

| 形式 | インポート対応 |
|---|---|
| `.ysm` | テクスチャとモデル付属アニメーションを含む YSM モデル。OpenYSM/YSMParser ベースのインポート処理を使用します。 |
| `.bbmodel` | Blockbench プロジェクトのキューブ/メッシュ、ボーン階層、テクスチャ、対応するアニメーション。 |
| `.zip` | 内容から YSM フォルダー、Blockbench モデルパック、Figura アバターパック、Bedrock モデルパックを判別します。 |
| Bedrock ジオメトリ | `.geo.json` / `geometry.json`。Bedrock パックには `.animation.json` ファイルや PNG テクスチャも含められます。 |
| `.gltf` / `.glb` | glTF モデルのローカルインポート。`.gltf` が参照する外部リソースも一緒に保存してください。 |

Figura パックからはモデルとテクスチャを読み込みます。Figura Lua の実行環境は提供しません。形式のインポートに対応していても、元のアプリケーションの全機能に対応するとは限りません。Cloud へのアップロードと共有は、選択したインスタンスが対応する形式に依存します。

<a id="features"></a>
## 機能

- **カスタム外観：** プレイヤーモデルの置き換え、テクスチャの切り替え、モデルが提供する設定の調整。
- **アニメーションホイール：** Z でモデル付属アクションを選択。対応モデルではアニメーションコントローラー、`loop` / `once` / `hold` 再生、Molang 式を利用できます。
- **モデル音声：** モデル付属のボイスや効果音を再生。Opus 音声のデコードに対応します。
- **モデル管理：** ローカルファイル、フォルダー、URL からのインポート、モデルの閲覧、グループ分け、お気に入り登録。
- **Cloud モデルライブラリ：** 全モデル、最近使用、お気に入り、自分のモデル、公開モデルを閲覧できます。全モデルでは検索語なしでアクセス可能なモデルを一覧表示します。
- **追加のモデル対象：** 対応するエンティティ、乗り物、投射物にもカスタムモデルを使用できます。利用できる対象は、モデルと選択したビルドの連携機能に依存します。

<a id="spm-cloud"></a>
## SPM Cloud：公式またはセルフホスト

内蔵の公式 Cloud、またはコミュニティ/セルフホストのインスタンスに接続できます。**SPM Cloud は独立したモデル・同期サービスであり、Minecraft サーバー用 MOD ではありません。** 外観を共有したいプレイヤーは同じインスタンスを選んでください。

- ゲームアカウントでログインするか、Cloud アカウントでログインして現在のゲームアカウントを連携します。利用可能な認証サービスと登録方法は Cloud 運営者が管理します。
- 連携済みアカウントはログインを自動復元し、失敗時には間隔を空けて再試行できます。手動でログアウトすると、インスタンスを再選択するまで自動復元は停止します。
- アカウント、モデル、ゲームアカウントの連携はインスタンスごとに独立しています。インスタンスを切り替えてもライブラリや連携は移行しません。
- 非公開モデルが自動で公開されることはありません。一般的なマルチプレイで表示するには公開モデルを使用してください。非公開モデルを選ぶだけでは、他のプレイヤーにアクセス権は付与されません。

セルフホストについては、独立した [SPM Cloud Rust バックエンド](https://github.com/sdf123098/spm-cloud)と [English](https://github.com/sdf123098/spm-cloud/blob/main/README.md) / [中文](https://github.com/sdf123098/spm-cloud/blob/main/README_zh.md)のセットアップガイドを参照してください。Docker Compose、Linux ネイティブ、Windows ネイティブでの運用に対応します。カスタム認証ゲートウェイや複数の認証サービスは Cloud 運営者が設定します。これらは Cloud サービス側の設定であり、Minecraft サーバーの変更は不要です。

<a id="compatibility"></a>
## MOD 互換性

SPM には Better Combat、Curios、Create、Iris/Sodium、スキンレイヤー描画との連携があります。利用可否は Minecraft のバージョン、ローダー、他の MOD のバージョンに依存し、すべての組み合わせを保証するものではありません。SPM を使うためだけに、これらの任意連携 MOD を導入する必要はありません。

<a id="faq"></a>
## よくある質問

### Minecraft サーバーにも SPM が必要ですか？

不要です。カスタムモデルを表示したいクライアントに SPM を導入してください。Cloud が Minecraft サーバーから独立して外観共有を処理します。

### 双方が SPM を導入したのに、お互いのモデルが見えません。

同じ Cloud インスタンスへの接続、ログイン、現在のゲームアカウントの連携と本人確認、プライバシーモードの無効化を確認してください。ローカルにだけインポートしたモデルではなく、アクセス可能な Cloud モデルを使用し、Cloud の接続状態も確認します。セルフホストでアクションが同期しない場合は、バックエンドが現在のアニメーションプロトコルに対応しているかも確認してください。

### Cloud なしでも SPM を使えますか？

ローカルモデルは使用できます。Cloud によるマルチプレイ共有には正常な Cloud 接続が必要です。Cloud の停止時には、共有や新しいモデルのダウンロードが中断することがあります。

### 外部認証サービスを使えますか？

選択した Cloud インスタンスで有効な認証サービスを使い、現在のゲームアカウントの本人確認を行ってください。Minecraft サーバーのログイン方式だけでは、認証済みの Cloud 連携は作成されません。

### README の翻訳は同じ内容ですか？

英語、中国語、日本語、韓国語で、章の順序、導入手順、マルチプレイ共有の条件、ビルド一覧を統一しています。章 ID も共通なので、`#multiplayer` などのリンクはどの言語でも使用できます。どの翻訳を読んでも利用条件は同じです。
